# Bíblia — Versões (dados)

Textos bíblicos usados pelo app [ExploraBíblia](https://github.com/daruanapp/exploraBiblia) para as versões
de tradução baixadas sob demanda (além da NVI, que vem embutida no app).

- `acf.json` — Almeida Corrigida Fiel
- `arc.json` — Almeida Revista e Corrigida (domínio público)

Formato: array de `{ book_id, chapter, verse, text }`, com `book_id` seguindo o
mesmo esquema de `books.json` do app principal.

Este repositório existe apenas para hospedar esses arquivos estáticos de forma
gratuita e pública (o app busca por URL direta), sem qualquer relação com o
código-fonte do app, que permanece em repositório privado.
